New components · Ant-style Switch and Segmented in detail

Both components match Ant Design's default sizing and behavior, with the brand color swapped to --color-primary-primary. Hover over them to see the interaction states.

Switch — "Friendly Names"

Off — gray track, handle on the left. On — purple track, handle slides right. Built to Ant's small-Switch spec (16px track, 12px handle, 2px padding). Label is clickable too.

Segmented — tab navigation

Three states of the segmented control. The selected pill has a white background with a soft shadow; unselected items hover with a faint gray fill. Reads as a single grouped widget, which is what tabs really are.

File pill · empty vs. loaded emphasis

The empty state needs to draw the eye — it's the gateway to using the app. The loaded state should be quiet so the user can focus on data. Same component, two visual weights.

Empty: ghost CTA — light purple background, purple border, purple icons. Clearly the action. Chevron at the end signals "go pick one" (replacing the swap icon since there's nothing to swap yet).

Loaded: quiet container — white background, gray border, gray icons. Hover it to see the purple border + soft glow (try it in the browser). Swap icon now appears because there's an actual file to replace.
